# Reproducibility Package
## Explainable Cyber-Physical Fusion Detection and Physics-Feasible Adversarial Robustness for Smart Grids

All results in the paper are regenerated by the 20 scripts below (fixed seeds throughout).
Run order matters only for Dataset 1: run `build_features.py` first — every Dataset-1 script reads its cached output (`results/features_ds1.parquet`).

## Setup

```
pip install -r requirements.txt
```

- Dataset 1: SmartGrid-CyberPhysical-Attack-Dataset → place under `Dataset/`
- Dataset 3: IEC-104/61850 traces (Matousek et al.) → place under `data/`

## Notes

- Random seeds are fixed in every script (RNG=42 unless stated in-script).
- Detector-comparison thresholds are calibrated on benign streams to a common 5% false-alarm rate; measured rates are reported in the paper's table captions.
- The IEEE 118-Bus detection results are produced by a **full end-to-end run** (`exp7c_ieee118_full.py`): the AC-WLS estimator is solved at every timestep with the Jacobian recomputed at every Gauss-Newton iteration, so no analytical identity is assumed. The earlier extrapolation (`exp7_ieee118.py`) and partial run (`exp7b_ieee118_partial.py`) are retained for reference only.
- The benign manifold is fitted on **estimated** states (the WLS output an operator actually observes), not on true power-flow states. Fitting on true states would hand the detector ground-truth information unavailable in deployment, and it yields an optimistically clean subspace.
- The 99.9%-variance rule is **not** used to pick the manifold dimension on either system. Applied to estimated states it returns K=20 of 27 on IEEE 14-Bus and K=165 of 235 on IEEE 118-Bus, in the latter case producing a badly miscalibrated detector (~43% false-alarm rate). On both systems K is instead selected by cross-validation on benign streams only, with no attacked data: K=6 on IEEE 14-Bus and K=8 on IEEE 118-Bus.
- Ramp-rate and step-bias detectability are reported **once**, from `exp6_manifold_detector.py`, where the temporal, manifold and fused tests are calibrated together to a common false-alarm rate. Earlier versions also reported separately calibrated ramp and step-floor curves from `exp5_ac_stealth_temporal.py`; because the two experiments used different monitoring horizons and thresholds they disagreed on the same quantity, so the exp5 versions have been withdrawn.
